I. TỔNG QUAN ĐỀ THI & YÊU CẦU ĐẠT ĐƯỢC

Bài thi giữa kỳ yêu cầu xây dựng ứng dụng quản trị người dùng (User Management Admin) đa nền tảng đáp ứng trọn vẹn 3 yêu cầu với thang điểm 10/10:

Tiêu chí Nội dung yêu cầu Điểm Kết quả
Yêu cầu 1 Sử dụng cơ sở dữ liệu Firebase / MongoDB thực hiện thêm, hiển thị email, matkhau, hoten, hinhanh trên nền tảng Web. 8.0 điểm Đạt 100%
Yêu cầu 2 Thực hiện phân hệ Admin: Đăng nhập, Xóa, Sửa người dùng và các chức năng nâng cao (Tìm kiếm realtime, Lọc & sắp xếp A-Z, Đổi theme Sáng/Tối, Xuất database JSON). 1.5 điểm Đạt 100%
Yêu cầu 3 Nhập được hình ảnh (chọn từ thư viện/camera/URL/presets) và hiển thị thông tin người dùng tối ưu trên nền tảng di động (Mobile). 0.5 điểm Đạt 100%
LƯU Ý NGHIÊM NGẶT THEO ĐỀ BÀI: Cơ sở dữ liệu CHỈ chấp nhận đúng 4 trường: email, matkhau, hoten, hinhanh. Tuyệt đối không tự bổ sung thêm bất kỳ trường nào khác trong JSON. Đã xuất kèm file database.json và users.json phục vụ chấm bài.

II. CÔNG NGHỆ SỬ DỤNG & LỆNH CÀI ĐẶT THƯ VIỆN

  • Framework Đa nền tảng: Flutter 3.47.4 (Dart 3.13.3), hỗ trợ build đồng thời cho Web (HTML5/Canvaskit/Wasm) và Di động (Android APK).
  • Cơ sở dữ liệu đám mây: Firebase Realtime Database (đồng bộ thời gian thực theo cấu trúc node REST).
  • Cơ sở dữ liệu MongoDB: Node.js Express REST API Server chuẩn bị sẵn tại thư mục server/.
  • Bộ nhớ đệm Offline: shared_preferences bảo đảm ứng dụng hoạt động 100% không bao giờ crash kể cả khi máy chấm không có mạng.

1. Lệnh tải các thư viện liên quan (pubspec.yaml)

# 1. Thư viện gọi API kết nối Firebase REST / MongoDB
flutter pub add http

# 2. Thư viện nhập hình ảnh từ máy và camera di động
flutter pub add image_picker

# 3. Thư viện lưu trữ dữ liệu offline SharedPreferences
flutter pub add shared_preferences

# 4. Thư viện giao diện phông chữ chuẩn Google Fonts
flutter pub add google_fonts

2. Lệnh khởi chạy ứng dụng

# Chạy trên nền tảng Web (Google Chrome)
cd flutter_user_admin
flutter run -d chrome

# Hoặc biên dịch bản Web tĩnh
flutter build web --release

# Khởi chạy trên Android Emulator
flutter emulators --launch Pixel_14
flutter run -d emulator-5554

III. KIẾN TRÚC MÔ HÌNH DỮ LIỆU & CƠ SỞ DỮ LIỆU CHUẨN

1. Cấu trúc Model Dart (Chỉ 4 trường bắt buộc)

class UserModel {
  final String email;
  final String matkhau;
  final String hoten;
  final String hinhanh;

  UserModel({
    required this.email,
    required this.matkhau,
    required this.hoten,
    required this.hinhanh,
  });

  Map<String, dynamic> toMap() => {
    'email': email.trim(),
    'matkhau': matkhau,
    'hoten': hoten.trim(),
    'hinhanh': hinhanh.trim(),
  };

  factory UserModel.fromMap(Map<String, dynamic> map) => UserModel(
    email: (map['email'] ?? '').toString().trim(),
    matkhau: (map['matkhau'] ?? '').toString(),
    hoten: (map['hoten'] ?? '').toString().trim(),
    hinhanh: (map['hinhanh'] ?? '').toString().trim(),
  );
}

IV. CÁC MÀN HÌNH CHỨC NĂNG & HÌNH ẢNH MINH HỌA THỰC TẾ

1. Màn hình Đăng nhập Quản trị viên (Admin Login)

Màn hình đăng nhập trang bị validation kiểm tra regex email, toggle ẩn/hiện mật khẩu, nút điền nhanh tài khoản Admin dự phòng (admin@gmail.com / Admin@123) và chuyển đổi giao diện Sáng / Tối.

Hình 2: Màn hình Đăng nhập Phân hệ Quản trị viên trên nền tảng Web

2. Màn hình Quản trị Người dùng trên Nền tảng Web (8.0 Điểm)

Bảng Data Table hiển thị trực quan 4 trường bắt buộc, đi kèm 3 thẻ thống kê KPI (Tổng người dùng, Đang hiển thị, Trạng thái CSDL), thanh tìm kiếm Live Search và bộ sắp xếp A-Z / Z-A.

Hình 3: Giao diện Quản trị viên & Danh sách người dùng trên nền tảng Web (Yêu cầu 1)

3. Giao diện Tối ưu trên Nền tảng Di động (Mobile - 0.5 Điểm)

Tự động nhận diện màn hình điện thoại (width < 850px) để chuyển sang giao diện Card View bo góc mượt mà, tối ưu thao tác chạm ngón tay.

Hình 4: Giao diện hiển thị danh sách người dùng trên nền tảng Di động (Yêu cầu 3)

4. Form Thêm & Sửa Người dùng (Nhập hình ảnh đa năng)

Hỗ trợ chọn ảnh từ Thư viện (Gallery), Chụp ảnh trực tiếp (Camera), nhập link URL ảnh ngoài, hoặc chọn nhanh từ bộ Preset Avatars có sẵn kèm Live Preview.
